# Security Policy

## Supported versions

Security fixes for the public Mirror site land on the default branch (`main`).

## Reporting a vulnerability

Please **do not** open a public issue for security reports that could expose users.

Email Gabriel (Caezarr) via the contact on [github.com/Caezarr](https://github.com/Caezarr), or use the contact in [`.well-known/security.txt`](.well-known/security.txt).

Include a short description, reproduction steps, and impact.

## Scope

This repository is the public product/privacy/support site for Mirror. Prefer coordinated disclosure for XSS, open redirects, or privacy-copy gaps that could mislead users.
