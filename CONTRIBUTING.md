# Contributing to mirror-site

Public privacy, support, and product pages for Mirror.

## Workflow

1. Branch from `main`.
2. Prefer small, reviewable HTML/CSS/SEO changes.
3. Check links, robots/sitemap, and OG meta after content edits.
4. Open a PR against `main`.

## Notes

- Static site (GitHub Pages style) — keep pages self-contained
- OG share image: prefer PNG for crawler compatibility (see issue #5)
