Mirror support

Help with the app and browser companion.

Mirror is currently in pre-release development. The notes below cover the local browser connection and the safest way to report a problem.

01

Browser observation

  1. Install Mirror using its signed direct-distribution package.
  2. Install the official Mirror browser extension.
  3. Open Mirror and confirm that the package-managed connector is present.
  4. Open the extension popup and explicitly enable local observation.
02

If events do not appear

  • Confirm that the extension toggle says observation is on.
  • Confirm that the selected browser reports its system connector as installed.
  • Restart the browser after installing or updating the Mirror package.
  • Reinstall the signed package if the system connector is reported missing.
  • Keep private apps and domains excluded unless you intentionally change those settings.
03

Report an issue

Open a ticket in the public support tracker. Include the Mirror version, macOS version, browser name, and a concise description of what happened.

Open a support ticket
